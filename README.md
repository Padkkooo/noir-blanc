# Noir&Blanc

Учебный проект: интернет-магазин селективной парфюмерии. Трёхзвенная архитектура: браузер (HTML/CSS/JS) → сервер Express (Node.js) → PostgreSQL `noir_blanc`.

**Репозиторий проекта:** https://github.com/Padkkooo/noir-blanc

## Состав репозитория

- `site/` — исходный код сайта: `server.js`, `public/`, `db/schema.sql`, `package.json`, `start.bat`.
- `sql/` — сценарии базы данных: схема, процедуры, триггеры, роли, безопасность, блокировка, тестовые данные.
- `docs/` — отчёты по учебной практике и приложения.
- `.env.example` — шаблон настроек подключения к PostgreSQL. Настоящий `.env` в репозиторий не включён.

## Запуск

1. Установить PostgreSQL и Node.js.
2. Создать базу `noir_blanc` и выполнить `site/db/schema.sql`.
3. Скопировать `.env.example` в `.env` и указать свои параметры.
4. В папке `site` выполнить `npm install` и `npm start`.
5. Открыть `http://localhost:3000`.

Проект подготовлен для учебной практики по теме «Разработка и администрирование базы данных интернет-магазина Noir&Blanc».
